Privacy Policy

Kartoffel Screen Pen is a macOS screen annotation tool that allows users to draw and highlight over any application using mouse input and keyboard shortcuts. We respect your privacy and design the app so that it does not collect, store, or transmit personal data.

Data Collection

Kartoffel Screen Pen does not collect, store, or transmit any personal data. We do NOT collect:

  • Mouse input data
  • Keyboard input data
  • Screen content or captures
  • Location data
  • Device identifiers or serial numbers

Accessibility Permission

The app requests Accessibility permission from macOS strictly for the following operational needs:

  • Detecting global mouse movements and clicks to render your drawings
  • Enabling drawing and annotation overlay over other applications
  • Handling user-defined keyboard shortcuts (e.g. toggle pen, clear screen)

Accessibility access is active only when you explicitly enable drawing mode. When drawing mode is inactive, no input monitoring occurs. We never log, record, or transmit any input captured through macOS Accessibility APIs.

Data Storage

Kartoffel Screen Pen does not store your input or screen content. All drawing data exists only in transient volatile memory during active annotation and is never persisted unless explicitly saved by you.

Third-Party Services

This app does not integrate with or use any third-party analytics, advertising networks, telemetry, or tracking SDKs.

Changes to this Privacy Policy

We may update this Privacy Policy from time to time. Any updates will be announced directly within app release notes or on this page.
